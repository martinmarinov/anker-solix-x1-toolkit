About this display. The dashboard polls the local server adaptively (2–20 s); the server holds one read-only MQTT subscription per site and publishes only the read-only realtime wake request. It never changes the plan or the controller. The editor writes only the plan and never switches mode or sends a charge-power value. The live feed is paused while the browser tab is hidden.
